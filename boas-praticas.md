# Boas práticas de Git e GitHub

1. **Commits pequenos e frequentes:** cada commit deve representar uma mudança lógica, o que facilita revisar e reverter.
2. **Mensagens de commit descritivas:** explique o que mudou e por quê, não use apenas "ajustes" ou "teste".
3. **Nunca trabalhar direto na main:** crie uma branch para cada funcionalidade ou correção e integre via Pull Request.
4. **Atualizar a main local antes de criar uma branch:** use `git pull` para evitar conflitos desnecessários.
